# OQENS-CLI

The Enterprise Command Line Interface for the OQENS community platform.

## Installation

Clone this repository and run:

```bash
npm install
npm link
```

## Usage

Run the CLI using the `oqens` command.

```bash
oqens --help
oqens login
oqens feed --table
oqens search users admin
oqens post view <id>
```
