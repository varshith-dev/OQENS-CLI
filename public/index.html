Built for developers

Everything you need to stay connected with your community, right from the command line.

Browser-based Login

No tokens to copy. The CLI opens your browser, authenticates, and saves your session — all in one flow.

Live Community Feed

Read discussions, view code snippets, and browse the latest posts from the OQENS community in your terminal.

Create & Interact

Publish posts, comment on threads, and like content — the full OQENS experience in your terminal window.

Quick commands

Get started in seconds with these simple commands.

oqens login
Authenticate via browser
oqens feed
Browse the live community feed
oqens post create
Publish a new post
oqens search "react"
Search posts and users
oqens post view <id>
Read a post and its comments
oqens post comment <id>
Reply to a discussion
